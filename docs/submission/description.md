# Game description

Owner: sudeimete (issue #19). Short description of the game for the submission. Language: Turkish.

3play, gerçek afetleri iki farklı gözden yaşatan bir farkındalık oyunu. Önce rolünü seçiyorsun: vatandaş ya da devlet. Sonra dünya dönüyor ve seni gerçek hayatta yaşanmış bir afetin içine bırakıyor. Kahramanmaraş depreminde (2023) karlı gecede ailenizi toplanma alanına götürüyor, Hint Okyanusu tsunamisinde (2004) Endonezyadaki köyleri dalgadan korumaya çalışıyor, Kara Cumartesi yangınında (2009) çiftlikten zamanında kaçmaya uğraşıyorsun. Her tur o olayın gerçek rakamlarıyla bitiyor. Bazen de dünya takılıyor ve seni bin yıl ileriye, 3026'daki bir Güneş patlamasının ortasına atıyor. Çünkü hayatın göremediğimiz boyutları vardır.
